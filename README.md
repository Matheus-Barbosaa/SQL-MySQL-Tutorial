# SQL & MySQL Tutorial

Projeto de estudos práticos em SQL e MySQL, desenvolvido durante minha evolução em Banco de Dados, desde consultas básicas até recursos intermediários e avançados para manipulação e análise de informações.

## Sobre o projeto

Este repositório reúne meu processo de aprendizagem em SQL e MySQL, desenvolvido a partir das aulas, conteúdos e exercícios da professora **Mrs. Data (@drlucienegomes)**.

O projeto registra os conceitos estudados e sua aplicação prática por meio de exercícios SQL, contribuindo para a construção do meu portfólio na área de Dados.

## Objetivo

Desenvolver uma base prática em SQL e MySQL, aplicando consultas, relacionamentos entre tabelas, agregações e outros recursos para compreender melhor a manipulação e a análise de dados.

## Tecnologias e ferramentas

- **SQL:** linguagem utilizada para consultar e manipular dados.
- **MySQL:** sistema de gerenciamento de banco de dados relacional utilizado nos estudos.
- **Git e GitHub:** versionamento e organização do projeto.

## Conteúdos estudados

- Consultas com `SELECT`, `WHERE`, `ORDER BY` e `LIMIT`.
- Agrupamentos e agregações com `GROUP BY`, `HAVING`, `COUNT`, `SUM` e `AVG`.
- Relacionamentos entre tabelas com `JOIN`.
- Combinação de resultados com `UNION`.
- Condições com `CASE`.
- Subconsultas e CTEs.
- Views, funções e stored procedures.
- Recursos para consulta, organização e análise de dados.

## Como executar

1. Instale e abra o MySQL Server e um cliente SQL, como o MySQL Workbench.
2. Abra os arquivos `.sql` na ordem indicada.
3. Execute os comandos de criação das tabelas antes das consultas que dependem delas.
4. Confira os resultados das consultas no cliente SQL.

**Importante:** os comandos devem ser executados em um ambiente MySQL compatível com a estrutura e os dados utilizados nos scripts.
