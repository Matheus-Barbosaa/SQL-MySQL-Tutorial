# SQL & MySQL Tutorial

> Projeto de estudos em SQL e MySQL, desenvolvido durante minha evolução em Banco de Dados, começando por consultas básicas com `SELECT`, `WHERE`, `GROUP BY` e `ORDER BY`, e avançando para `JOINs`, `UNION`, `CASE`, CTEs, Views, Functions, Procedures e análise de dados.

## Sobre o projeto

Este repositório reúne meu processo de aprendizado em **SQL e MySQL**, desenvolvido a partir das aulas, conteúdos e exercícios da professora **Mrs. Data (@drlucienegomes)**.

O projeto foi construído durante minha evolução nos estudos, colocando em prática os conceitos aprendidos e registrando os exercícios realizados ao longo desse processo.

## Objetivo

Desenvolver uma base prática em **SQL e MySQL**, utilizando consultas e diferentes recursos do banco de dados para compreender melhor a manipulação e análise de informações.

Este projeto também faz parte da construção do meu **portfólio na área de Dados**.
